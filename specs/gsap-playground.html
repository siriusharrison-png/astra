Hover lift

Micro-feedback. No Play button — just hover or focus it.

scale: 1.06power2.out0.2s
↑ interactive on hover / keyboard focus
el.onmouseenter = () => gsap.to(el,
  { scale: 1.06, y: -4, duration: 0.2 })
el.onmouseleave = () => gsap.to(el,
  { scale: 1, y: 0, duration: 0.2 })

Scroll-linked (ScrollTrigger)

Scroll through this box. The square's position, rotation and scale are tied to scroll progress with scrub: true — it stays visible the whole way, never hidden.

progress 0%
GS
gsap.to(runner, {
  xPercent: 140, rotation: 180, scale: 0.7, ease: "none",
  scrollTrigger: { trigger: track, start: "top 80%", end: "bottom 20%", scrub: true }
})

Using it in a real project

This skill is the recipe book — the GSAP library itself lives in each project. Pick one way to load it, then paste any recipe above. All plugins (SplitText, DrawSVG…) ship free in 3.13+.

Option A · CDN

Fastest — plain HTML or a prototype. Nothing to install.

<script src="…/gsap/3.13.0/gsap.min.js"></script>

Option B · npm

React, Vue, or any build setup.

npm install gsap
import { gsap } from "gsap"
